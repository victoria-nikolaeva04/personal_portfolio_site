The Department Discord Bot Calendar Feature is an interactive bot command. It pulls Google Calendar events into a Discord message, so a community can see what is coming up without leaving the chat.

## What it does

- Pulls events from Google Calendar into a Discord message
- Includes a filter system so people can narrow down which events they see

## How it's built

The bot is written in TypeScript. It uses the Google API to read calendar events and MongoDB to store data.
