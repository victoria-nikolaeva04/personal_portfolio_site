# Personal Resume Site
My personal portfolio site for recruiter and peers to see my work and thought process
------------------
## Planning
### Sections of Website: 
    - Header
         - Photo
         - Who am I?
    - Experience
         - Work Experience Timeline
         - Eductaion
    - Projects
    - About
         - 'Off the Clock'
         - Field Notes
         - Toolbox/Skills
    - Contact Me

### Tech Stack
TypeScript, Tailwind CSS v4, HTML, TanStack Router, React 19, Vite

### Scripts
- `npm run dev` – start the Vite dev server on port 3000
- `npm run build` – create a production build
- `npm run lint` – run ESLint
- `npm run format` – format with Prettier and auto-fix with ESLint

### Design
Theme: A little cute greenhouse (I am a growing developer after all) 
Color Palette: Purples/Plum, Greens, Cream, Marigold yellow 
Fonts: Fraunces, DM Sans, Caveat
